15

18
DR-017ALU_IXORI: Performs bitwise XOR between rs1 and sign-extended 12-bit immediate: rd = rs1 ^ imm32.
19

20
DR-019ALU_ISRLI: Shift Right Logical Immediate. rd = rs1 >> imm[4:0]. Zeros shifted into MSBs.
21
DR-020ALU_ISRAI: Shift Right Arithmetic Immediate. rd = $signed(rs1) >>> imm[4:0]. Sign bit (rs1[31]) is replicated.
22

23

24

25
DR-024ALU_RSUB: 32-bit register subtract: rd = (rs1 - rs2)[31:0]. Ignores underflow.
26
DR-025ALU_RSLL: Shift Left Logical by rs2[4:0]: rd = rs1 << rs2[4:0]. Bits rs2[31:5] are ignored.
27
DR-026ALU_RSRL: Shift Right Logical by rs2[4:0]: rd = rs1 >> rs2[4:0]. Zeros shifted into MSBs.
28
DR-027ALU_RSRA: Shift Right Arithmetic by rs2[4:0]: rd = $signed(rs1) >>> rs2[4:0]. Sign bit replicated.
29
DR-028ALU_RSLT: Signed register compare: rd = ($signed(rs1) < $signed(rs2)) ? 1 : 0.
30
DR-029ALU_RSLTU: Unsigned register compare: rd = ($unsigned(rs1) < $unsigned(rs2)) ? 1 : 0.
31
DR-030ALU_RXOR: Bitwise XOR between rs1 and rs2: rd = rs1 ^ rs2.
32
DR-031ALU_ROR: Bitwise OR between rs1 and rs2: rd = rs1 | rs2.
33
DR-032ALU_RAND: Bitwise AND between rs1 and rs2: rd = rs1 & rs2.
34

35

36
DR-035BranchBEQ: Branch taken if rs1 == rs2: target = PC + imm_b. If not taken, PC = PC + 4.
37
DR-036BranchBNE: Branch taken if rs1 != rs2: target = PC + imm_b. If not taken, PC = PC + 4.
38
DR-037BranchBLT: Branch taken if $signed(rs1) < $signed(rs2). Signed comparison.
39
DR-038BranchBGE: Branch taken if $signed(rs1) >= $signed(rs2). Signed comparison.
40
DR-039BranchBLTU: Branch taken if $unsigned(rs1) < $unsigned(rs2). Unsigned comparison.
41
DR-040BranchBGEU: Branch taken if $unsigned(rs1) >= $unsigned(rs2). Unsigned comparison.
42
DR-041BranchBranch Shadow Flush: When a branch/jump is taken, instructions in IF and ID stages are completely flushed without committing.
43

44
DR-043LSUSW: Writes 32-bit value in rs2 to memory at rs1 + imm. Drives data_we_o=1 and byte enables data_be_o=4'b1111.
45
DR-044LSULH: Reads 16-bit halfword and sign-extends bits 15:0 to 32 bits into rd: rd = {{16{data[15]}}, data[15:0]}.
46
DR-045LSULHU: Reads 16-bit halfword and zero-extends to 32 bits into rd: rd = {16'h0000, data[15:0]}.
47
DR-046LSUSH: Writes 16-bit halfword to memory. Drives data_be_o=4'b0011 (offset 0) or 4'b1100 (offset 2).
48
DR-047LSULB: Reads 8-bit byte and sign-extends bit 7 to 32 bits into rd: rd = {{24{data[7]}}, data[7:0]}.
49
DR-048LSULBU: Reads 8-bit byte and zero-extends to 32 bits into rd: rd = {24'h000000, data[7:0]}.
50
DR-049LSUSB: Writes 8-bit byte to memory. Drives one-hot byte enable: be = 1 << addr[1:0].
51
DR-050LSUData OBI Handshake: Memory responder may insert wait states on data_gnt_i (0-6) and data_rvalid_i (0-10). Core holds signals stable.
52
DR-051LSUMisaligned Memory Access: Unaligned LW/SW (addr[1:0]!=00) or LH/SH (addr[0]==1) handled via split accesses without hanging.
53

54
DR-053MUL_DIVMULH: Signed x Signed upper 32-bit product: rd = ($signed(rs1) * $signed(rs2))[63:32].
55
DR-054MUL_DIVMULHU: Unsigned x Unsigned upper 32-bit product: rd = ($unsigned(rs1) * $unsigned(rs2))[63:32].
56
DR-055MUL_DIVMULHSU: Signed x Unsigned upper 32-bit product: rd = ($signed(rs1) * $unsigned(rs2))[63:32].
57
DR-056MUL_DIVDIV: Signed integer division: rd = $signed(rs1) / $signed(rs2). Truncates towards zero.
58
DR-057MUL_DIVDIVU: Unsigned integer division: rd = $unsigned(rs1) / $unsigned(rs2).
59
DR-058MUL_DIVREM: Signed remainder: rd = rs1 % rs2. Sign of REM strictly matches sign of dividend rs1.
60
DR-059MUL_DIVREMU: Unsigned remainder: rd = $unsigned(rs1) % $unsigned(rs2).
61
